# Screenshot source folder

Place only approved, real WebApp screenshots here. Do not create stand-in images,
mockups, or generated artwork.

The first product config expects these exact filenames:

- `home.jpeg`
- `setup-choose.jpeg`
- `setup-surprise.jpeg`
- `setup-names.jpeg`
- `play-funny.jpeg`
- `play-wild.jpeg`
- `end-highlights.jpeg`

Keep the paths in the product config stable. The validator reports missing assets
by slide and asset ID before a future render is allowed.
