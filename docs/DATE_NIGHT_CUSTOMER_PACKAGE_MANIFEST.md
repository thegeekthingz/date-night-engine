## Upload architecture and ZIP alternative

Etsy currently permits up to five files, up to 20 MB each, and supports PDF and ZIP: [Etsy Help — How to Manage Your Digital Listings](https://help.etsy.com/hc/en-gb/articles/115015628347-How-to-Manage-Your-Digital-Listings), checked 2026-11-02. This five-PDF architecture fits the file-count limit. Existing printable originals are each under 0.1 MB; the future START HERE PDF must also be checked against the limit. No need to ZIP the present printables solely for size.

If direct upload becomes inconvenient, keep 01_START_HERE_Date_Night.pdf as a standalone first-open file and supply 02_Date_Night_Printable_Bonus.zip containing the four approved numbered printable PDFs. The ZIP must be under 20 MB. Explain extraction in START HERE if this fallback is selected. ZIP does not waive Etsy's per-file size limit. Direct five-PDF delivery remains the approved default; do not send customers through external file-hosting accounts.
